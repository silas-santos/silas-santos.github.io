# Silas Santos · Portfólio de BI

Relatórios e painéis feitos no Power BI com **dados públicos** do Rio Grande do Sul: saúde (DATASUS, INEP, SICONFI) e agro (IBGE, INMET, MAPA).

Este site mostra a **versão web interativa** de cada projeto: os mesmos visuais (Deneb / Vega e HTML) e os mesmos dados que estão no Power BI, para abrir direto no navegador, sem login.

| Projeto | Tipo | Tema |
|---|---|---|
| A chuva que decide a safra | Painel de TV | Agro |
| A cidade está preparada para os bebês? | Relatório | Saúde |
| Como nascem os gaúchos | Relatório | Saúde |
| Quanto dos leitos SUS está ocupado? | Painel de TV | Saúde |
| Dengue no RS | Painel de TV | Saúde |
| Panorama das Internações SUS RS | Painel de TV | Saúde |
| Clínica odontológica (dados fictícios) | Painel de TV | Exemplo |

Todos os dados são públicos e agregados: nenhum dado individual de paciente, segurado ou aluno.
